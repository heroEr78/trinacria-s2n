Detailed Description

The class that represents a lua node. A Node represents a script part of a Net. Every script to be a node has to have: *a Public() function that returns a table containing the properties of a script *an optional Events() function that returns a table of functions: the functions are events that every other node can advise the script of *an Id string field, a unique-identifier for the script.
